# Návrh Attack & Defense rozšírenia pre fit-ctf

Tento priečinok je samostatný pracovný balík k prezentácii návrhu. Zvyšok
repozitára som nemenil.

Odporúčané poradie čítania:

1. [01-architektura-frameworku.md](01-architektura-frameworku.md) - čo dnes framework
   obsahuje, aké vrstvy má a ako spolu tečú dáta.
2. [02-navrh-attack-defense.md](02-navrh-attack-defense.md) - návrh, ako nad existujúcu
   architektúru doplniť Attack & Defense režim.
3. [03-prezentacna-osnova.md](03-prezentacna-osnova.md) - stručná osnova na prezentáciu
   vedúcemu.
4. [04-navod-ako-postupovat-pri-vlastnom-navrhu.md](04-navod-ako-postupovat-pri-vlastnom-navrhu.md)
   - presný pracovný postup, ako si návrh poskladať vlastnými rozhodnutiami.
5. [05-databazove-schemy.md](05-databazove-schemy.md) - aktuálna databázová schéma a
   navrhovaná schéma pre Attack & Defense režim.

Diagramy sú vložené ako Mermaid bloky. Dajú sa zobraziť napríklad v GitHub Markdowne,
v Mermaid Live Editore alebo v prezentačnom nástroji s Mermaid podporou.
